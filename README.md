## 🚀 Current Projects

### 🔐 Zero Trust Security Framework for Cloud Environments
> *MSc Research Project — Mount Kenya University*

Designing and evaluating a Zero Trust Architecture (ZTA) for cloud-native environments. The framework integrates:
- **Micro-segmentation** for lateral movement prevention
- **IAM with RBAC/ABAC** for fine-grained access control
- **AI-driven anomaly detection** for real-time threat response
- **Policy enforcement** across distributed services

**Stack:** `Python` · `Docker` · `Kubernetes` · `Istio` · `Terraform` · `Prometheus`
