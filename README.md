## 🚀 Current Work

### 🔐 Zero Trust Security Framework for Cloud Computing Environments
*MSc Research · Mount Kenya University*

Design and evaluation of a Zero Trust Architecture for multi-tenant public cloud, focused on cross-tenant isolation and lateral movement prevention.

- Fine-grained access control with **RBAC / ABAC**
- **Istio-based micro-segmentation** between services
- **ML anomaly detection** (Random Forest, SVM) trained on **CICIDS 2017**
- Working prototype: flow records pass through a **PEP → ML service → PDP → enforcement** pipeline, with benchmarked performance
- Methodology: Design Science Research

**Stack:** Python · Docker · Kubernetes · Istio · Terraform · Prometheus

### 🛡️ Enterprise Network Security @ FinSprint
- Firewall administration and policy management on **FortiGate**
- Office **VLAN segmentation**, designed and tested in a virtual lab before production rollout
- Endpoint protection deployment with **CrowdStrike Falcon**
